# EPL-Data-Practice-Project

An exploratory analysis of English Premier League match data, conducted as a method of deepening my understanding oof SQL.
I hope to develop this repository into a full analysis as I go. I aim to investigate how matchday results and external factors can impact matchday attendance.

# Data
The primary dataset used is [this dataset from Reza Asadi on Kaggle](https://www.kaggle.com/datasets/rezagooner/comprehensive-english-premier-league-match-dataset). To smooth out inconsistencies in the attendance data, attendance data was downloaded from [FBREF](https://fbref.com/en/comps/9/history/Premier-League-Seasons).
